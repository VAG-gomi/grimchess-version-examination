# Limitations

1. The four Old APKs are not chronologically ordered.
2. The Current pinned repository contains one F1 APK; the earlier Current-related hash is recorded but not present as a Current artifact in that commit.
3. Hash identity proves byte identity, not historical context or runtime equivalence.
4. APK entry differences in manifests, DEX, resources, and signature metadata require semantic analysis before behavioural interpretation.
5. The recovered Old source is not proven to be the exact source that produced every Old APK.
6. Build configuration comparison cannot recover missing original dependency resolution, signing keys, or build transactions.
7. No Old-versus-Current runtime experiment is performed here.
8. No result is labelled a cause of the Current runtime error.
